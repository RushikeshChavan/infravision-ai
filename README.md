# InfraVision AI

## Short Description

InfraVision AI is a government infrastructure monitoring platform that provides secure, scalable, and intelligent oversight for infrastructure projects throughout their lifecycle.

## Project Vision

Build a production-grade monitoring solution that combines modern web technologies, geospatial mapping, real-time alerts, and AI-driven insights to support transparent infrastructure delivery and decision-making.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT
- Socket.IO
- OpenStreetMap
- AI Assistant
